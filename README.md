# Paradise Nursery

## Project Name
Paradise Nursery Shopping Application

## Project Description
Paradise Nursery is an online plant shopping application that allows users to browse houseplants by category, view plant details and prices, add plants to a shopping cart, update quantities, and calculate the total cost of their purchases.

## Features
- Browse plants across multiple categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View the total cart price.

## Technologies Used
- React
- JavaScript
- CSS
- Redux Toolkit

## Purpose
This project demonstrates the development of a dynamic and user-friendly e-commerce application.
